Getting Started with My Blog

October 12, 2026 intro meta

Welcome to my new personal blog! I'm excited to share my thoughts, projects, and learning journey with you. This blog is built as a simple static site using HTML, CSS, and JavaScript — no frameworks, no build steps, just clean code.

Why a Blog?

I've been thinking about starting a blog for a while now. The main reasons:

  • Learning in public: Writing forces me to clarify my thinking and document what I learn
  • Building a portfolio: A blog shows not just what I've built, but how I think
  • Connecting with others: Sharing my journey might help someone else on theirs

Why Static?

After exploring various platforms (WordPress, Ghost, Medium, etc.), I decided to build my own static site. Here's why:

  • Speed: Static files served from a CDN are incredibly fast
  • Simplicity: No database, no server-side code, no security patches
  • Control: I own my content and my platform completely
  • Cost: Free hosting on GitHub Pages, Netlify, or Vercel
  • Longevity: HTML files will work forever; platforms come and go

What You'll Find Here

I plan to write about:

  • Web development tutorials and learnings
  • Project showcases and post-mortems
  • Tools and workflows I find useful
  • Thoughts on software craftsmanship

The Tech Stack

This blog runs on:

  • HTML: Semantic markup for accessibility and SEO
  • CSS: Custom properties, Grid, Flexbox, and modern features
  • JavaScript: Vanilla JS for minor interactions (dark mode toggle, etc.)
  • Hosting: GitHub Pages (free, reliable, version-controlled)
