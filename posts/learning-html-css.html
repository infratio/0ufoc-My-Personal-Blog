CSS: The Presentation

CSS (Cascading Style Sheets) handles the visual presentation. The concepts that clicked for me:

The Box Model

Every element is a box with content, padding, border, and margin. Understanding box-sizing: border-box was a game-changer — it makes sizing predictable.

*, *::before, *::after {
  box-sizing: border-box;
}

Flexbox for One-Dimensional Layouts

Flexbox makes it easy to align items in a row or column:

.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}

CSS Grid for Two-Dimensional Layouts

Grid is perfect for page layouts and complex arrangements:

.project-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 1.5rem;
}

Custom Properties (CSS Variables)

Define values once, use everywhere. Makes theming and maintenance easy:

:root {
  --color-accent: #2563eb;
  --space-md: 1rem;
  --font-sans: system-ui, sans-serif;
}

.button {
  background: var(--color-accent);
  padding: var(--space-md);
  font-family: var(--font-sans);
}

Responsive Design

Making sites work on all screen sizes using mobile-first approach:

/* Mobile first - base styles */
.container {
  padding: 1rem;
}

/* Tablet and up */
@media (min-width: 768px) {
  .container {
    padding: 2rem;
  }
}

/* Desktop */
@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
    margin: 0 auto;
  }
}
